# AI News and Shipping a Paid AI Car Recommendation Platform

## TL;DR

- Use the LLM to **understand the user**, not to make the final pick. Keep the **recommendation deterministic**.
- AI can fill data gaps, but a **human admin approves** new data before users see it.
- Build a **golden prompt set** and rerun it every time you change the model or the prompt.
- AI is **overly agreeable** and has no common sense without context. Tell it about **concurrency and throughput** upfront.
- With AI coding, a job estimated at **28 weeks** shipped in about **12 weeks**.

## Talk 2: Shipping a Paid AI Car Recommendation Platform with Claude

This talk was a real client project. The platform was built for a **Korean fintech client**. It is paid, and it is live in production on **Azure**. It was delivered in September.

The team was small and split between Australia and Korea. The speaker worked from Sydney with IT and marketing staff on the Korea side.

### How it works

1. The user types what they want in plain language.
2. **Claude Haiku** extracts the intent using a 7-point rubric. Examples: fuel efficiency, brand origin, car type.
3. The system scores cars from a **Postgres** database and returns the **top 3**. This scoring is deterministic.
4. **Claude Sonnet** writes the description for each car.

### Key design decisions

- **The LLM extracts intent only.** It does not choose the car. The same input gives the same result.
- **An AI research agent fills data gaps.** It searches the web for missing car data. But a human admin must approve the data before it is served.
- **Guardrails.** The user prompt is wrapped in a context layer before it reaches the Anthropic or OpenAI API.

### Why not just use ChatGPT?

- The data is grounded in a real database.
- The output is structured.
- Invoicing and financing are in scope for phase 2.

### How they test it

They keep a **golden prompt set**. Each prompt has an expected output. AI or a human scores the result. The pass threshold is about **95 to 98%**.

They rerun the full set on every model change and every prompt change.

### Timeline and tools

- Active work was about **3 months**, between May and September.
- Without AI, the estimate was **28 weeks**. AI coding saved about **16 weeks**.
- Tools: **Claude CLI, Claude Code, Claude API (Haiku and Sonnet)**, ComfyUI, ChatGPT, Gemini, ElevenLabs.
- The promotional video was made with **ComfyUI** animation plus an HTML overlay written by Claude.

The platform launched on **September 28**. In 2 days, 10 to 12 Korean media outlets covered it.

### Lessons learned

- **AI has no common sense without enough context.**
- **AI is overly agreeable.** One example: when the user's budget was too low, it suggested secondhand cars instead of saying no.
- **Say concurrency and throughput upfront.** AI will not think about them on its own.
- **AI changed how the team works**, not just how fast. Testing, communication, and coding all changed.
